# 단원 1 · 합동 (Congruence) — 세부 스펙

> 📍 교육과정: 초5 2학기 3단원 「합동과 대칭」
> 📐 화면 구성: **단일 보드** (찾기와 증명이 같은 행동)

---

## 설계 변경 기록

세 번 고쳤습니다. 매번 같은 방향의 실수를 반복했습니다.

| 이전 | 문제 |
| --- | --- |
| 홈에서 도형 먼저 선택 | 선택 자체가 학습이 아님 |
| 1단계 쌍 찾기 → 2단계 포개기 | 찾기와 증명을 별개 행동으로 분리 |
| **돌리기·뒤집기 버튼 제공** | **아이에게 각도를 선택하게 함** |

마지막이 가장 중대합니다. **회전 버튼이 있다는 건 "방향이 중요하다"고 알려주는 것**이고,
이 단원의 존재 이유가 "방향이 달라도 합동"임을 증명하는 거라 모순입니다.

---

## 핵심: 아이는 도형만 움직인다

```
아이: 도형을 끌어다 다른 도형 위에 놓는다
         ↓
시스템: 90도 × 4회전 × (뒤집기 유무) 를 스스로 시도한다
         ↓
시스템: "돌려서 겹쳤어! 합동이야"  →  도형이 알아서 맞춰진다
```

**실패해도 시스템이 판단합니다:**

| 상황 | 메시지 |
|---|---|
| 이미 겹침 | "겹쳤어! 합동이야" |
| 90도 회전하면 겹침 | "돌려서 겹쳤어! 합동이야" |
| 회전+뒤집기 하면 겹침 | 자동으로 맞춘 뒤 "합동이야" |
| 같은 모양인데 크기가 다름 | "모양은 같지만 크기가 달라서 합동이 아니야" |
| 모양 자체가 다름 | "이건 모양이 달라 — 합동이 아니야" |

---

## 도형 12개: 5쌍 + 방해 2개

### 쌍 (각각 회전이나 뒤집기가 필요)

| 쌍 | 도형 | 필요한 조작 | 교과서 연결 |
|---|---|---|---|
| 가 · 사 | 직사각형 (넓은 것 / 세로로 긴 것) | 90도 회전 | 기본 개념 |
| 나 · 다 | 사다리꼴 ( 눕혀짐 / 서 있음) | 90도 회전 | 방향이 다름 |
| 라 · 마 | 비이등변 삼각형 ( 거울상 ) | 뒤집기 | 모양이 다름 |
| 아 · 자 | 화살표 ( 오른쪽 / 위쪽 ) | 270도 회전 | **가장 확실한 사례** |
| 차 · 카 | 물고기 ( 오른쪽 / 거울상 ) | 뒤집기 | 방향이 다름 |

### 방해 도형 2개

| 도형 | 정체 | 아이가 배우는 것 |
|---|---|---|
| 타 | 작은 직사각형 | **크기가 다르면 합동이 아님** |
| 파 | 정오각형 | 모양이 다르면 아님 |

### 왜 직사각형·사다리꼴인가

**정사각형은 쓸 수 없습니다.** 90도 회전 대칭이라 돌려도 자기 자신이 되어
"돌려야 한다"가 사라집니다. 처음엔 정사각형 쌍을 넣었다가 테스트가 막았습니다.

**이등변삼각형도 쓸 수 없습니다.** 좌우 대칭이라 거울상이 아예 같은 모양입니다.
요청하신 "다양한 삼각형"에 맞춰 세 변의 길이가 모두 다른 삼각형으로 바꿨습니다.

**화살표는 방향이 가장 확실**해서 이 단원의 핵심 주제를 증명하는 데 제일 좋습니다.
아무리 뒤집어도 화살촉 방향은 숨길 수 없는데, 그래도 90도 돌리면 겹칩니다.

## 판정 엔진: 세 가지 조건

```
겹침만 검사   → 작은 게 큰 게 안에 들어가므로 통과   ← 오판!
합동만 검사   → 크기가 다르면 실패                  ← 올바름
모양만 검사   → 다른 모양이면 실패                 ← 올바름
```

**세 가지를 분리해서** "크기가 달라"를 독립된 케이스로 보고합니다.
코드에 이 사례를 주석으로 남겨뒀습니다. 나중에 리팩터링하면 회귀가 생깁니다.

### 회전 기준: 꼭짓점 평균이 아니라 무게중심

```
꼭짓점 평균으로 회전 → 화살표가 180도 회전 후 기울어짐
                       → 겹침 판정 0.9 → 실패로 오판
무게중심(polygonCentroid)으로 회전 → 정확히 일치
```

또 회전한 뒤 **기준 도형의 중심에 정렬(seat)해야** 합니다.
그렇지 않으면 사다리꼴·물고기가 몇 픽셀 어긋나서 100%에 못 미룹니다.
