# 단원 1 · 합동 (Congruence) — 세부 스펙

> 📍 교육과정: 초5 2학기 3단원 「합동과 대칭」
> 📐 화면 구성: **단일 보드** (찾기와 증명이 같은 행동)

---

## 설계 변경 기록

이전 설계는 3단계였고, **둘 다 틀렸습니다.**

| 이전 | 문제 |
| --- | --- |
| 홈에서 도형 먼저 선택 | 아이가 뭘 해야 하는지 모름. 선택 자체가 학습이 아님 |
| 1단계: 쌍 찾기 → 2단계: 포개기 | **찾기와 증명이 별개 행동으로 분리됨** |

교과서적으론 ①②③로 나누지만, 이 앱에서는 한 화면이 맞습니다.
합동의 정의가 "완전히 겹치는 것"이므로 **겹쳐 보는 행위 자체가 정답 확인**입니다.

## 화면: 도형 8개가 놓인 보드

```
┌──────────────────────────────────────────────┐
│  가                나                    다    │
│                                              │
│                                              │
│              라                                    │
│   마                          바(90도 기울어짐)      │
│                                              │
│  아                                            │
└──────────────────────────────────────────────┘
   ⭐ 0 / 3        [↺90°] [↻90°] [45°] [🪞뒤집기]
```

### 조작 흐름 (한 화면 안에서)

```
1. 도형을 누른다        → 잡힘 (꼭짓점 점 표시)
2. 드rag               → 다른 도형 위로 이동
3. 안 맞으면           → 돌리기 / 뒤집기
4. 완전히 겹치면       → ⭐ + "합동" 표시
```

**놓지 않는 순간에도 잡힌 상태가 유지**됩니다.
이동 → 회전 → 뒤집기가 끊기지 않고 이어집니다.

## 3쌍의 구성과 각각의 이유

| 쌍 | 도형 | 아이가 하는 일 | 교과서 연결 |
|---|---|---|---|
| **가 · 사** | 정사각형 2개 | 바로 겹침 | 기본 개념 확인 |
| **나 · 라** | 삼각형 2개 | 바로 겹침 | 눈으로 확인 |
| **다 · 바** | **사다리꼴 2개** | **90도 돌려야 겹침** | **방향이 달라도 합동** |

### 왜 사다리꼴인가

처음엔 **직사각형**으로 만들었는데, 테스트가 막았습니다.

```
직사각형 90도 회전 → 자기 자신이 됨 (회전 대칭)
→ 두 개를 처음부터 겹치면 100% 일치
→ "돌려야 한다"가 사라짐
```

**회전 대칭이 없는 사다리꼴**로 바꿨습니다. 평행한 두 변의 길이가 달라서
90도를 돌려야 넓은 쪽과 좁은 쪽이 맞습니다.

```
다: 사다리꼴 (0도)  → 겹침 82.5%
바: 사다리꼴 (90도) → 겹침 100%  ✅
```

이 쌍이 없으면 **"방향이 달라도 합동"**을 아이가 직접 해볼 방법이 없습니다.

## 방해 도형 2개

| 도형 | 정체 | 아이가 배울 점 |
| --- | --- | --- |
| **마** | 큰 정사각형 | **크기가 다르면 합동이 아님** |
| **아** | 정오각형 | 모양이 다르면 아님 |

### 마가 특히 중요합니다

마는 가·사와 **모양이 완전히 같습니다.** 크기만 다릅니다.

여기서 판정 로직이 두 개 다 필요해집니다:

```
겹침만 검사   → 작은 정사각형이 큰 것 안에 완전히 들어가므로 contained=true  ← 오판!
합동만 검사   → 크기가 다므로 isCongruent=false                              ← 올바름
둘 다 검사    → 마는 걸러짐                                              ← 정답
```

코드 주석에 이 사례를 남겨두었습니다. 나중에 "겹침만 보면 되겠다"로
리팩터링하면 큰 정사각형이 걸러지지 않는 회귀가 생깁니다.

## 판정 결과 표시

| 상태 | 배너 |
| --- | --- |
| 잡은 도형 없음 | 도형을 **누른 뒤 끌어다** 겹쳐 보세요 — ⭐ 0 / 3 |
| 잡은 도형 있음 | **삼각형**을 잡았어. 안 맞으면 **돌리기**나 **뒤집기**를 눌러봐 |
| 3쌍 완료 | 모두 찾았어! 방향이 달라도 겹치면 합동이야 |

### 도구 버튼

잡은 도형이 없으면 **비활성화**됩니다.
아무것도 하지 않는 버튼은 아무것도 가르치지 않기 때문입니다.
