> 🔀 브랜치: `main`

---

## ⚠️ 이전 설계의 오류와 이번 수정

**이전 설계:** 포개기 → 변·각 관찰 → 다시 그리기 → 더 찾아보기

**문제:** 교과서 흐름과 달랐습니다. 교과서는

> ① 합동 정의 → **② 여러 도형 중 합동인 것 찾기** → ③ 대응점·대응변·대칭각
> → ④ 선대칭 → ⑤ 점대칭

즉 **"합동인 도형 찾기"가 정의 직후에 오는 2번째 단계**인데,
이전 설계는 이를 맨 마지막("더 찾아보기")으로 밀어버렸습니다.
도구 조작을 먼저 배치해서 "찾기"를 학습의 후반으로 미룬 것이 오류입니다.

**이번 설계:** 교과서 순서를 따르되, 단계 1과 2는 분리합니다.

---

## 1단계 · 합동인 도형 찾기 (드래그 연결)

> 교과서 ②에 해당. "아래에서 합동인 도형을 찾아보면 가와 사, 나와 라, 다와 바"

### 화면 형태

**흩어져 있는 도형들** (5~8개) 중 **합동인 쌍을 드래그로 연결**합니다.

```
┌─────────────────────────────────────────┐
│                                         │
│   ▲          ■                 ◆        │   ← 흩어져 있음
│      ◆          ▲       □               │
│         □                       ▲       │
│   ◆                               ■     │
│                                         │
│  ─── 가와 사를 이어 보세요 ───────────    │   ← 드래그 힌트
└─────────────────────────────────────────┘
```

### 규칙

| 항목 | 결정 |
|---|---|
| 도형 수 | 5~8개 (합동 쌍 + 합동 아닌 도형 혼합) |
| 정답 쌍 수 | 2~3쌍 |
| 조작 | 드래그로 두 도형을 연결 |
| 판정 | 연결한 순간 **포개어 봐야** 확정 (단계 2와 연결) |
| 오답 | 정답을 알려주지 않음 → 힌트 → 재도전 |

### 합동 아닌 도형의 종류 (혼입용)

교과서 첫 문제의 구성을 따릅니다.

| 종류 | 아이가 배울 점 |
|---|---|
| **모양 다름** | 삼각형 vs 정사각형 → 모양부터 다름 |
| **크기 다름** | 정사각형 vs 큰 정사각형 → 모양은 같지만 크기가 다름 |
| **방향 다름** | 정사각형이 90° 회전한 것 → **이것도 합동!** |
| **변의 길이만 다름** | 마름모 → 모양은 같지만 변 길이가 다름 |

> ⚠️ **"방향 다름"은 반드시 포함해야 합니다.**
> 초5에서 방향이 달라도 합동이라는 게 핵심입니다.
> 오답 보기에 넣으면 아이가 교과서와 반대로 배웁니다.
> → **거짓 보기로 넣고, 고르면 "잘 봤어요! 그런데 방향이 달라도 합동이에요!"라고 알려줍니다.**

## 2단계 · 직접 포개어 보기 (드래그 겹치기)

> 1단계에서 고른 쌍이 **실제로 맞는지 손으로 확인**합니다.

### 화면 형태

좌우로 떨어진 두 도형. 아이가 하나를 끌어다 다른 하나에 포개면 됩니다.

```
┌─────────────────────────────────────────┐
│                                         │
│    ◆  기준 도형                    ▲     │   ← 왼쪽 고정
│                              ▲            │   ← 오른쪽을 끌어다
│                                         │
│  ─── ▲를 ◆에 겹쳐 보세요 ────────────   │
└─────────────────────────────────────────┘
```

### 규칙

| 항목 | 결정 |
|---|---|
| 조작 | 드래그로 도형을 기준 도형에 포개기 |
| 판정 | 겹친 순간 실시간 표시 |
| 성공 | ⭐ + "같은 모양이야!" + 축하 애니메이션 |
| 실패 | 정답 미공개, 다음 행동만 안내 |

### 메시지

| 상태 | 메시지 |
|---|---|
| 합동 | "같은 모양이야! 대단해!" |
| 안 겹침 | "왼쪽 도형에 겹쳐 보게 해 보자" |

> ⚠️ **"모양은 같은데 크기가 달라" 메시지는 이번 단계에서 쓰지 않습니다.**
> 크기 조절 도구가 제외되었으므로 이 상황 자체가 만들어지지 않습니다.
