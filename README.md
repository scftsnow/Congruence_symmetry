# 합동과 대칭 (Congruence & Symmetry)

초등학교 5학년 수학의 **합동(合同)** 과 **대칭(對稱)** 을
태블릿 브라우저에서 손으로 만져보며 익힐 수 있는 학습 웹앱입니다.

> 🧒 대상: 초등 5학년
> 🛠 React 19 + TypeScript + Vite / SVG 렌더링
> 🌐 GitHub Pages 배포 · 계정 없이 바로 사용

📐 **전체 설계 명세는 [SPEC.md](./SPEC.md) 참고**

## 왜 이 앱인가

합동과 대칭은 종이 위에서만 배우면 개념이 잘 잡히지 않습니다.
이 앱은 아이가 **직접 도형을 움직여 보면서** 배웁니다.

### 핵심 철학

> **학습의 중심은 자유 시뮬레이션이다.
> 문제는 그 시뮬레이션에서 파생해 나온다.**

일반적인 학습 앱과 흐름이 **정반대**입니다.

| 일반 학습 앱 | 이 앱 |
| --- | --- |
| 문제를 먼저 제시 | **작업대**를 먼저 열어 자유롭게 놀게 함 |
| 정답 제출 → 채점 | 두 도형을 겹치는 순간 **시스템이 직접 감지** |
| 틀리면 정답 공개 | 틀리면 **힌트 → 재도전** |
| 정해진 그림 조작 | **나만의 작업대**를 아이가 구성 |

**놀이(Play) → 발견(Discovery) → 문제(Problem)**

---

## 학습 범위 (코어 4개)

1. **합동인 도형 찾기** — 모양·크기가 같은 도형 찾기
2. **대칭축 찾기** — 접었을 때 겹치는 선 찾기
3. **대칭인 도형 그리기** — 대칭축을 기준으로 도형 완성하기
4. **실생활에서 찾기** — 주변의 대칭·합동 발견하기

## 아이가 쓰는 도구 4종

| 도구 | 배우는 개념 |
| --- | --- |
| 🚚 **옮기기 (밀기)** | 평행이동 |
| 🔄 **돌리기** | 회전 |
| 🪞 **뒤집기** | 반사 / 대칭이동 |
| 🔍 **크기 조절** | 크기가 달라지면 합동이 아님을 체감 |

## 문제 유형

- 🧲 **도형 맞추기** — 드래그해서 겹치기 (실시간 판정)
- ✏️ **손그리기** — 대칭축을 손가락으로 직접 그리기

오답 시 정답을 알려주지 않고 **힌트를 준 뒤 재도전**시킵니다.

## 실행 방법

```bash
npm install
npm run dev      # 개발 서버 (localhost:5173)
npm run build    # 프로덕션 빌드 → dist/
npm run preview  # 빌드 결과 미리보기
```

## 기술 스택

- React 19 + TypeScript + Vite
- SVG 도형 렌더링 (확대해도 흐려지지 않음)
- `localStorage` 진도 저장 (로그인 없음, 서버 불필요)
- GitHub Pages 배포
